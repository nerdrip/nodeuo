# Code Of Conduct

This project is technical, weird, and occasionally messy. Keep it workable.

## Expected Behavior

- Be respectful.
- Assume good intent, but ask for clarity when something is unclear.
- Give actionable feedback.
- Accept review without making it personal.
- Keep public discussions free of harassment, threats, slurs, and personal
  attacks.

## Unacceptable Behavior

- Harassment or abuse.
- Publishing private information.
- Repeated off-topic disruption.
- Submitting proprietary assets or secrets.
- Evading maintainer decisions after a moderation call.

## Enforcement

Maintainers may edit, hide, close, or remove issues, PRs, comments, and access
when behavior damages the project or community. Serious security or moderation
matters should be handled privately first.
